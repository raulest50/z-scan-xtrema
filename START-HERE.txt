SESIÓN
Una conexión WebSocket por operador; token aleatorio conservado por pestaña.
No hay caducidad por inactividad del usuario. Uvicorn gestiona ping/pong.
Al detectar desconexión se detiene la simulación y reserva 10 s para reconexión.
Liberar equipo detiene el movimiento antes de liberar la reserva.
Ejecutar UNA instancia con UN worker. No usar --reload durante control físico.
El token es exclusión mutua, no autenticación de usuarios. La interfaz Newport
externa no queda bloqueada por esta aplicación.

INTEGRACIÓN PYNQ (pendiente)
Identificar primero el intérprete que importa PYNQ y sus dependencias.
Crear el entorno a partir de ese intérprete; considerar system-site-packages
si PYNQ está instalado globalmente, verificando que no se oculten sus versiones.
No copiar el .venv de Windows a Linux. uv.lock fija dependencias de la app,
pero no captura bibliotecas ni controladores del sistema/PYNQ.
No se modifica el servicio Jupyter ni el puerto 80.
ZSCAN_ORIGINS permite una lista separada por comas de orígenes web autorizados.

HARDWARE REAL (verificado 2026-10-06)
XPS-RL V1.0, 192.168.0.254:5001, Group1 / Group1.Pos, IMS600CCHA.
Límites consultados: 0..600 mm. No representan zonas libres de obstáculos.
HomeSearchSequenceType: MechanicalZeroAndIndexHomeSearch; timeout Newport 26 s.
La interfaz exige confirmar recorrido despejado para inicializar y hacer homing.
Estado 0/7 -> GroupInitialize -> 42 -> GroupHomeSearch -> READY.
Si ya está READY no se fuerza re-homing mediante un reset automático.
GroupMoveAbsolute solo se admite en READY y dentro de límites consultados.
Velocidad configurada leída inicialmente: 200 mm/s. Al solicitar movimiento,
la app aplica como máximo 10 mm/s y conserva aceleración/jerk. Este ajuste afecta
al grupo también si luego se usa la web Newport. No se escribe stages.ini.
El homing conserva los parámetros del fabricante; no usa este límite de 10 mm/s.
Parada normal: GroupMoveAbort; cancelación de homing/inicialización: GroupKill,
que deshabilita el grupo y obliga a referenciarlo de nuevo.
Timeout/error incierto: no repetir movimiento; intentar GroupKill, bloquear
órdenes hasta confirmar parada. Nunca interpretar un timeout como movimiento terminado.
Sockets asíncronos separados para telemetría, orden y parada.
Sin enlace de red no se puede garantizar una parada: disponer de parada física.
El inicio y reinicio normales de la app solo consultan; no hacen homing automático.
No operar simultáneamente desde la web Newport: esta app no controla esos accesos.
